# EarthPulse 3D — Social Video & Publishing Plan

Target format: **9:16 vertical**, 40–50 seconds, 1080×1920.

The video should show the real EarthPulse interface and real public live-data behavior. Do not insert fake earthquake/event counts or imply that galaxy/star close-ups are live telescope footage.

## Recording notes

- Record the website itself; do not replace the core demo with AI-generated interface footage.
- For live-event footage, use whatever events the public APIs return at recording time.
- If a feed is temporarily unavailable, record another section and retry later rather than fabricating data.
- Galaxy and Solar System scenes are educational visualizations and are not spatially to scale.
- Keep taps slow enough to be visible, but edit cuts tightly.
- Use the same screen recording as the base for TikTok, Instagram Reels, Facebook Reels and YouTube Shorts.
